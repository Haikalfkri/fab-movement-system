# 📊 FAB Report System

The **FAB Report System** is a reporting application designed to manage, generate, and display fabrication process reports efficiently.  
It is built using **.NET MVC 4.7** and leverages modern web frameworks along with an SQL database for structured data management.

---

## 🚀 Technologies Used

- **[Visual Studio Professional 2022](https://visualstudio.microsoft.com/)** (Update 12)
- **[SQL Server Management Studio v20](https://learn.microsoft.com/sql/ssms/overview)**
- **.NET MVC 4.7**
- **[EPPlus 7.6.0](https://epplussoftware.com/)** – For Excel file generation and manipulation.
- **[Bootstrap 4.5.2](https://getbootstrap.com/docs/4.5/getting-started/introduction/)** – Responsive UI design.
